# v1.4.4

**去掉一处无谓写盘 / 日志噪音**（功能与 1.4.3 相同）。

## 修了什么

`localConfigFile` 是**启动期引导字段**（决定本用户配置文件在哪），但它被算进了
「本用户配置 vs 共享 profile」的差异比较里。于是每次 `app-boot/config-reload`
（任何插件保存设置都会发）都会误报一条：

```
设置已同步到本用户配置（localConfigFile）→ C:\Users\<你>\.dsh\remote-access-config.json
```

并把本用户配置文件白写一遍 —— 内容没变，只是 `updatedAt` 变了。

现在：

- `localConfigFile` 不参与差异比较（`BOOTSTRAP_KEYS`）；
- 首次种子改为**归一化后的完整配置**，第一次热重载也不会再把 `listen` 之类的默认值
  当成「刚保存的改动」；
- 没有真实改动时，`config-reload` 不写文件、不打那条日志。
